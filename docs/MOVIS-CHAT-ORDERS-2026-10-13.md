# 채팅 모션·선택형 설치·주문 복사 개선

## 변경
- 새 사용자 메시지는 우측 아래에서 짧게 등장하고, 새 AI 답변은 페이드와 상승 모션으로 표시된다. 저장된 대화는 다시 등장 애니메이션을 재생하지 않는다.
- 말풍선 호버에 2px 상승·테두리·광택 반응을 적용한다. 키보드 포커스에도 강조하며 터치에서는 시간을 항상 표시한다.
- AI 대기 중 신호 막대, 스트리밍 중 라인 등장·커서·상단 빛 흐름을 제공한다. 실제 응답을 지연시키는 가짜 타이핑은 추가하지 않았다.
- 이전 사용자 요청에 따라 OS 동작 줄이기 설정에서도 이 CSS 모션을 유지한다. WebGL에 의존하지 않는다.
- 연결 설정에 Windows 설치 다운로드와 접을 수 있는 안내를 추가한다. 페이지를 열었다고 설치·다운로드·로그인을 시작하지 않는다.
- 신규 설치의 Windows 자동 시작은 기본 해제다. 설치 안내에서 Y를 입력하거나 명시적으로 EnableAutoStart를 지정했을 때만 등록한다. 이미 사용자가 설정한 이 PC의 자동 시작은 유지한다.
- 주문 작성·상세·내역·저장된 장바구니의 복사/공유 텍스트에 연락처와 주소를 포함한다. 주문 기록을 우선하고 없는 값만 ID 또는 유일하게 일치하는 거래처명으로 보완한다. 동명이인·잘못된 ID·정보 없음은 추측하지 않는다.

## 검증
- 무비스·스마트스토어 안전장치·주문 연락처 테스트 36개 통과.
- Chromium 1366×768: 신규/기존 메시지 구분, 대기·스트리밍·완료 전환, 호버 강조 확인.
- Chromium 390×844 터치 및 reduced-motion 에뮬레이션: 동일 모션 재생, 가로 넘침 없음 확인.
- 이미지 첨부·붙여넣기·모델 선택·설치 안내 UI 회귀 검사 통과.
- 다른 실제 PC 설치 및 iPhone/Android 실기기 실행은 검증하지 않았다. 모바일 GPT 인증은 여전히 외부 등록·서버 준비 전 미완료다.

데이터베이스의 주문·거래처 데이터는 변경하지 않았다. 연락처 추가는 복사되는 텍스트만 변경한다.
