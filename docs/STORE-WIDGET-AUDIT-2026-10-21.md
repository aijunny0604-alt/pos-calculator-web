# 스마트스토어 상태 위젯 점검 — 2026-10-21

## 확인한 오류와 수정

목록은 조회 기간의 접수 주문뿐 아니라 해당 기간에 발주확인·발송한 이전 주문과 기간 밖 처리대기도 포함했다. 반면 단계 위젯은 접수일만 집계해 같은 화면의 발송 건수가 달랐다. 집계와 목록을 `src/lib/storeOrderView.js`의 공통 조회·상태 판정으로 통합했다.

- 단계별 건수는 마켓·검색·접수/작업 기간을 함께 반영한다. 단계 선택 후 다시 누르면 해제된다.
- 배송완료/취소 숨김 상태에서도 해당 단계 위젯을 누르면 그 단계 전체를 볼 수 있다.
- 진행 단계의 취소·반품에는 완료 건과 활성 요청이 포함된다. 별도 빠른 확인의 취소·반품 **요청**은 처리할 요청만 집계한다. 같은 함수로 클릭 결과를 구한다.
- 빠른 확인 위젯은 기간 밖 미처리를 놓치지 않도록 전체 기간 기준이며 화면에 명시했다. 마켓·검색 조건은 반영한다.
- 오늘/오늘 매출은 오늘 접수 기준이며, 클릭 목록도 같은 기준이다. 조회 대상은 접수·작업일/처리대기 기준이므로 오늘 접수 건수와 다를 수 있다.
- 이미 발송되거나 배송중인 주문의 오래된 자동처리 플래그를 대기 건수에서 제외했다. 사용자 지정 종료일은 다음 날 자정 미만으로 비교해 마지막 1초가 빠지지 않게 했다.
- 배송중·배송완료는 상품별 네이버 `productOrderStatus`도 반영한다. 대표 주문이 로컬 `shipped`로 남아 있어도 모든 활성 상품이 배송중/완료에 도달했으면 위젯·목록 배지·스텝퍼·CSV를 함께 갱신한다. 일부 상품만 완료됐거나 상태가 누락되면 주문 전체를 완료로 올리지 않는다. 송장번호나 경과 시간으로 상태를 추정하지 않으며 DB 값을 덮어쓰지 않는다.
