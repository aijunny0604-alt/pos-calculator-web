# 스마트스토어 미발송 상시 모니터링 — 2026-10-22

## 수정 이유와 동작

내부 주문 등록을 처리 완료로 간주하던 기존 isOrderPending 조건 때문에, 발주확인 후 미발송 주문이 조회 날짜를 벗어나면 목록·단계 위젯에서 빠졌다. 스토어 출고 모니터링은 별도 isStoreAwaitingDispatch 판정으로 분리했다.

- 오늘·1주일·사용자 기간에서도 결제완료/발주확인 후 미발송은 계속 포함한다. internal_order_id 및 converted는 발송 완료로 간주하지 않는다.
- 발송 대기 위젯, 발주확인 단계, 목록 요약, 기간 밖 안내, 카드 배지가 같은 기준을 사용한다. 검색·마켓 필터는 유지한다.
- 발송 성공 시각/발송·배송중·배송완료, 취소 성공/취소·반품·교환, 미결제, 진행 중 클레임은 미발송에서 제외한다. 오늘 발송한 건은 오늘의 발송 단계에 남을 수 있다.
- 송장 입력만 한 상태, 요청 큐, 발송 실패는 완료가 아니므로 계속 표시한다. 상품별 네이버 배송 상태도 확인한다.
- 내부 전환된 미발송에도 발송 버튼이 표시되며, 일괄 발송의 대상 판정도 같은 기준이다. 실제 발송 요청 처리 코드는 변경하지 않았다.
- 최신 200건에 오래된 미발송 후보 전체를 합친다. 페이지 단위 조회·ID 중복 제거·상품 조회 상한 대응을 적용했다. 조회 실패 시 정상 0건으로 바꾸지 않고 기존 목록과 재조회 안내를 유지한다.
- 모바일 알림 배너의 문구·버튼이 여러 좁은 열로 갈라지지 않도록 줄바꿈을 보완했다.

## 검증

- 전체 테스트: 161 통과 / 0 실패 / 1 건너뜀(MOVIS_TEST_URL 미설정).
- 오늘/다음날/7일 후, 내부 등록/converted, 송장만 입력/요청 큐/실패, 발송·취소 성공, 상품별 배송중/완료, 미결제·클레임, 검색·마켓·토글 조합.
- 가상 대기 503건 + 최신 200건, 중복 1건을 합쳐 702건. 마지막 대기 주문까지 조회하며 실패는 예외로 전달.
- 로컬 가상 자료: 오늘 선택 + 발주확인 위젯 3건 = 목록 3건. 과거 2건 포함. 검색 1건·단계 해제 확인.
- PC 기본 1280px, 모바일 360px, 태블릿 768px에서 확인. 360/768px 문서 가로 넘침 없음, 브라우저 콘솔 오류 없음. 실제 iOS/Android 기기 검증은 미실시.
- 운영 DB 읽기 검증: 160건 조회, 오늘 발주확인 위젯 1건 = 목록 1건. 이전 날짜·내부 등록 1건 포함, 발송 대기 총 2건. 운영 주문/발송/입금은 변경하지 않았다.
- 배포 후 운영 화면: 오늘 + 발주확인 1건 유지, 해제 2건/재선택 1건, 오늘 선택 유지, 콘솔 오류 0건. 내부 전환된 가상 주문의 발송 모달 진입·닫기도 확인했다(등록 미실행).
- 프로덕션 빌드 57.48초 성공. 기존 청크 크기 등 빌드 경고는 유지.
