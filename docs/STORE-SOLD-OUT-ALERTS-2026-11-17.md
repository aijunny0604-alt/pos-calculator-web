# 스토어 품절 알림

스마트스토어 화면에서 동기화된 상품과 옵션의 재고 변화를 확인한다. 첫 조회에서 이미 품절된 항목은 기준으로만 저장하고, 이후 판매 중에서 품절로 바뀐 상품과 사용 중인 옵션의 재고가 양수에서 0으로 바뀐 경우 알림을 표시한다. 재입고 후 다시 품절되면 다시 알린다.

확인 기준과 미확인 알림은 브라우저별로 저장한다. 스토어 화면을 열 때와 표시 중 30초마다, 동기화 이벤트와 화면 복귀 시 갱신한다. 현재 확인 시각과 수동 확인 버튼을 표시한다. 네이버 API 직접 실시간 수신이 아니라 매장 PC에서 동기화한 자료 기준이므로 동기화가 늦거나 화면을 닫은 동안 품절 후 재입고된 변화는 놓칠 수 있다. 다른 모달이 열려 있으면 알림 표시를 기다린다.

검증: 품절 전환·초기 기준·중복 방지·재입고·오래된 자료·저장 오류 단위 테스트, 데스크톱 및 모바일 알림·새로고침·다른 모달과의 충돌 테스트. 운영 상품을 변경하는 실거래 검증은 하지 않았다.
