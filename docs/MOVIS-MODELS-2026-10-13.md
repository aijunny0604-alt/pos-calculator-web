# MOVIS 모델 선택과 기기 연결 현황

## 구현
- 새 브라우저는 `자동 선택`이 기본값이다. account/read의 실제 요금제를 표시하고 model/list의 isDefault 모델을 사용한다. 권장값이 없으면 표시 가능한 첫 모델을 사용한다.
- 직접 선택한 모델은 해당 브라우저에 저장된다. 해당 모델이 사라지면 다른 모델로 몰래 전환하지 않고 재선택을 안내한다.
- 요청 직전에 계정 연결과 모델 목록을 다시 확인한다. 요금제 이름으로 모델 권한을 가정하지 않는다. 실제 요청 성공 여부가 최종 접근 확인이다.
- 기존에 저장된 수동 모델 설정은 유지한다. 자동 선택으로 전환할 수 있다.

## 검증
- 모델 선택 단위 테스트 3개 통과.
- 무비스 단위 테스트 26개 통과, 실제 브리지용 테스트 1개는 별도 환경 변수 없이 실행해 제외.
- 가상 계정 UI 테스트: 실제 요금제 표시, 자동 추천 표시, 수동 선택 저장·복원, 자동 선택 복귀, 390px 화면 넘침 없음.
- Vite 빌드 성공. 기존 minify/chunk 경고가 남아 있다.

## 기기 연결의 미완료 범위
- 현재 브리지는 127.0.0.1에서만 실행된다. 이 변경만으로 다른 PC나 모바일이 연결되지는 않는다.
- 모바일 포함 원격 사용 요청은 재개되었다. 본인 계정의 여러 기기인지 사용자별 계정인지 확인 중이다.
- 원격 사용에는 인증된 연결 경로가 필요하다. 공용 무인증 터널이나 OpenAI 토큰을 웹 프런트에 포함하는 방식을 사용하지 않는다.
- 호스팅형 사용자별 구독 연동은 공식 Sign in with ChatGPT 등록·지원 범위를 확인한 뒤 구성해야 한다.
