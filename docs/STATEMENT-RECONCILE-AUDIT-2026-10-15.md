# 명세서 대조 점검 — 2026-10-15

상태: 2026-10-15 사용자 승인으로 운영 배포. 소스 c22157d6, Pages 25e6c91d7dee72d7f663b19d556f4a2bfdf8689f. 실제 주문/입출금/대조 기록은 수정하지 않았다.

## 원인과 수정

- [P1] 제품명을 비교하지 않고 금액 근사치만으로 다른 제품도 일치 처리했다. 수량 불일치도 금액 폴백으로 통과했고, 합계만 맞으면 누락이 아니라는 문구를 표시했다. 제품명·규격·수량·금액이 모두 맞을 때만 일치로 바꿨다.
- [P1] uncertain을 무시하고 미판독 금액을 0으로 바꿔 무상 품목으로 통과시켰다. 미판독은 null로 보존하며, 불확실한 행·품목합계/명세서합계 차이는 확인 필요로 처리한다. 쉼표 금액을 정상 숫자로 읽는다.
- [P2] 거래처 일부 문자열 및 같은 금액 주문 여러 건, 인근 날짜 여러 건을 자동 합산했다. 거래처 정확 비교·어순 보정 후 모호한 후보는 별도로 안내한다. 날짜 없는 문서를 전체 주문에 대조하지 않는다.
- [P2] 한 장을 처리하는 중 추가한 대기 이미지가 완료 시 지워질 수 있었다. 처리한 이미지 ID만 대기열에서 제거한다. 조회 및 기록 저장의 즉시 중복 실행도 막았다.

## 제품명 처리

대소문자·전각·공백·어순, 스텐/스테인리스/스테인레스/STS 및 mm·파이·도 표기를 정규화한다. 숫자의 순서·개수·소수점, H/Y 및 좌/우는 보존한다. 금액 오차는 고정 5원 이내만 허용한다. 같은 상품 여러 줄의 묶음은 수량·금액 모두 일치하며 조합이 유일할 때만 허용한다. 서로 다른 규격을 섞어 적은 복합 묶음이나 역조합은 자동 일치하지 않고 확인 대상으로 남긴다.

## 판독 및 검토 UI

명세서 전처리 최대변을 1600→2400px로 조정했다. 판독 프롬프트는 빈칸/미판독을 null로 반환하고 예시 내용을 복사하거나 숫자를 추측하지 않도록 보강했다. 원본 이미지와 판독 이름·규격·수량·공급가액·세액을 확인/수정하면 즉시 재대조한다. 실제 주문 변경은 하지 않는다. 기록 저장 후에는 해당 결과 편집을 잠근다. 모바일 결과표는 내부 가로 스크롤을 사용한다.
