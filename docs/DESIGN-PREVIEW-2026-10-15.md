## 상태

배포하지 않은 로컬 변경이다. GitHub push, PR, Pages, Windows 배포 패키지 갱신을 수행하지 않았다.

미리보기: http://127.0.0.1:5186/pos-calculator-web/design-preview.html

샘플 상품·주문·거래처를 실제 화면 컴포넌트에 연결했다. 미리보기 진입점의 fetch 대체와 CSP로 외부 통신을 차단한다. 저장 요청은 403으로 거부하며, 실제 매장 자료를 읽거나 저장하지 않는다. 이 화면의 ONLINE 표시는 샘플 데이터 응답에 따른 것으로 운영 연결을 의미하지 않는다. 정상 제품 진입점 main.jsx는 이 가상 통신 모듈을 가져오지 않는다.

## 점검·개선

- 색상: 밝은 업무 화면, 네이비 메뉴, 청록색 주요 액션. 성공·주의·오류 의미 색상 유지.
- 메뉴: 선택 상태, 아이콘, 간격, 호버 이동 통일. 모바일 메뉴 글자 줄바꿈 방지와 안전영역 반영.
- 위젯: 지표 카드 여백·숫자·모서리·음영 통일. 모바일 2열 배치.
- 입력·표: 입력창 모서리, 포커스 표시, 행 간격, 숫자 정렬 개선.
- 모달: 주요 14개 업무 모달 외곽의 공통 시각 클래스, 중립적인 배경과 그림자, 짧은 등장 모션.
- 공통 확인창: 제목/본문/버튼 영역 분리, 긴 내용 본문 스크롤, 고정 하단 버튼, Escape/Tab 포커스 관리와 닫은 뒤 포커스 복귀.
- 입금 모달: 제목과 아이콘 정리, 입금/출금 탭의 의도된 두 줄 배치, 하단 저장 버튼 유지.
- 한국어 문장 단위 줄바꿈, 긴 주소 넘침 방지. 터치 버튼과 입력 영역 확대.
- 무비스의 다크 화면과 기존 애니메이션은 유지. 사용자 후속 요청에 따라 일반 UI도 OS reduced-motion과 관계없이 짧은 모션을 유지한다.

## 실제 수행한 검증

Chromium의 1366×768 및 360×844에서 메뉴 17개를 열어 확인했다: 대시보드, 제품 주문, 주문 내역, 메모, 저장 장바구니, 송장, 거래처, 명세서, 재고, 번웨이, 매입 발주, 단가표, 대여·불량, AI 주문, 스마트스토어, 관리자, MOVIS.

모바일 수정 후 360×844에서 17개 메뉴를 재검증했다. 수평 영역 밖 주요 버튼·입력·제목 없음, 페이지 오류 없음. 스크롤 가능한 가로 표는 의도된 가로 스크롤로 구분했다.

확인/긴 내용/거래처 선택/입금 등록 모달은 1366, 360, 390, 768px 폭에서 열고 닫았다. 추가로 360×640 DPR3, 390×844 DPR3, 412×915 DPR2.625, 768×1024 DPR2, 1024×768 DPR1.25, 1920×1080 DPR1에서 긴 확인창, 업체 선택 후 입금 모달, 실제 주문 상세를 점검했다. 본문 스크롤, 하단 버튼의 화면 내 위치, 모달 폭, 키보드 포커스, 화면 오류 검증 통과.

재현 스크립트: tests/design-audit.mjs, tests/design-modals.mjs. 이미지와 JSON은 tests/.artifacts/design-*에 있다.

## 범위 제한

실물 iPhone/Safari, Samsung Internet, Android 키보드 표시·브라우저 주소창 변화, 실제 Windows 배율 설정은 검증하지 않았다. DPR 시험은 기기 에뮬레이션이며 실제 OS 배율 검증이 아니다. 스마트스토어·매입 등의 일부 화면은 빈 상태이므로 모든 데이터 조합·오류 상태·중첩 모달을 검사한 것은 아니다. 인쇄/PDF 결과는 이번 디자인 검증 범위에 포함하지 않았다. 운영 데이터가 채워진 상태의 검토와 실기기 검증 후 배포 여부를 결정한다.

기본 미리보기의 상단 테스트 도구 바는 제거했다. 모달 검증 도구는 별도 `?tools=1` URL에서만 표시한다. 사이드바 상단 로고는 가로·세로 중앙 정렬한다.

추가 디자인 정리: 페이지별 blue/indigo 기본 액션 색상을 청록색 체계로 연결했다(인쇄 제외). 성공·경고·삭제 색상은 유지한다. 결제 수정/일괄 입금/명세서 모달에 공통 하단 액션 스타일과 닫기 버튼 크기를 적용했다. 페이지 전환 420ms, 모달 360ms, 배경 240ms. `tests/design-motion.mjs`에서 reduced-motion 두 조건 모두 실제 animationName/duration과 위젯 호버 변위를 확인했다.
