# 고객 응대 및 상세 UI 개선 (2026-10-16, 배포 승인)

## 반영 범위
- 택배송장 카드: 업체명 강조, 주소 영역 분리, 연락처 구분선, 모바일 세로 배치.
- 고객 상세: 요약 카드 톤 통일, 모바일 미수 금액 우선 배치, 긴 연락처 줄바꿈.
- 주문 상세: 연락처 카드, 밝은 헤더, 합계 상세 기본 접기 및 하단 공간 정리.
- 스토어 고객 응대: 상품 Q&A 조회, 답변 초안 작성·복사 및 판매자센터 연결.

## 실행과 제한
- `Start-StoreCare.ps1`로 읽기 전용 연결 프로그램 실행 (127.0.0.1:43128).
- 기존 사용자 홈 `naver-sync-bridge`의 설정과 의존성 사용. 인증정보를 프런트엔드로 전달하지 않음.
- Q&A 답변은 판매자센터에서 최종 등록. 이 구현에는 답변 전송 API가 없음.
- 리뷰는 공식 API 미지원으로 판매자센터 연결과 초안 작성·복사만 제공.
- 초안은 현재 화면 상태에만 유지되며 화면을 떠나면 사라짐.
- 자동 시작·모바일 원격 중계는 이번 변경에 포함하지 않음.

## 검증
- 실제 계정의 최근 30일 미답변 Q&A 읽기 조회 성공 (4건). 답변 전송 없음.
- 390×844 모바일 및 1280×720 데스크톱에서 샘플 고객/주문/송장 화면 확인.
- 회귀 테스트: 109 통과, 1 건너뜀, 실패 없음. 최종 프로덕션 빌드 성공 (56.90초).
- 실제 인쇄 및 고객 응대 전송은 실행하지 않음.
