# 주문 수정 시 포장 상태 점검

상품 행·옵션·수량이 바뀌면 주문을 저장하기 전에 포장 체크를 초기화한다. 단가·연락처·메모만 바뀌면 유지한다. 공유 포장 상태를 확인하거나 해제하지 못한 경우 주문 변경을 중단하고 오류를 표시한다. 같은 기기에서 요청한 포장 체크 저장과 초기화는 주문별 순서대로 처리한다. 주문 저장 자체가 실패해도 포장완료는 복구하지 않아 다시 확인하도록 한다.

주문 목록과 송장 화면, 스토어 연결 주문의 배지는 현재 주문 품목 수와 저장된 포장 품목 수가 다르거나 완료 체크 수가 부족하면 완료로 보이지 않는다. 상세 화면에서도 품목 변경 후 체크 상태를 다시 읽는다. 기존 기록은 품목 식별 정보를 저장하지 않으므로 과거에 같은 행 수로 제품만 교체된 사례는 완료 여부를 역추적할 수 없다. 다른 기기에서 동시에 포장 체크와 주문을 수정하는 상황은 DB 단일 트랜잭션이 아니므로 완전한 동시성 보장은 별도 서버 개선이 필요하다.

당일 기존 주문에 합산할 때 포장 상태 해제 또는 주문 수정이 실패하면 새 주문을 대신 만들지 않고 합산을 중단한다. 저장 실패 시 입력한 주문도 유지한다.

검증: 상품 추가·제거·수량·옵션·교체·단가 변경, 공유 저장 실패, 늦게 끝나는 포장 저장의 순서, 완료 배지 불일치, 샘플 화면의 수정·재포장·오류 표시를 테스트했다. 운영 주문은 변경하지 않았다.
