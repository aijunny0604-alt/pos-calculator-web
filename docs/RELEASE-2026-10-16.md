# 스토어 발송 상세 및 명세서 보완 배포 — 2026-10-16

사용자 배포 요청으로 반영한다.

- 스토어 PC 상세/카드 화면에 상품별 지연 여부·사유·설명, 발송 기한, 발주확인 일시/상태, 발송 일시와 클레임 상태를 표시한다.
- 각 상품주문 raw_payload를 구분해 사용한다. 날짜는 한국 시간이며 누락/잘못된 날짜는 미제공이다. 지연 처리 일시는 현재 데이터에 없으므로 미제공으로 표시한다.
- 배송완료/취소 상품은 기한 초과로 표시하지 않는다. 네이버 반영 전 POS 요청 대기와 재시도 시각은 별도 안내한다.
- 명세서 쉼표 금액 저장, 겹치는 금액 후보 매칭, 최신 주문 재대조, 미판독 저장 차단 및 판정 배지 일관성 보완을 함께 반영한다.

검증: 전체 테스트 109 통과, 브리지 환경 미설정 1 건너뜀. Vite 프로덕션 빌드 성공. 샘플 화면에서 지연/일반 발송 정보와 날짜 표시 확인. 실제 주문 상태나 운영 DB를 변경하지 않았다. 실제 명세서 사진 OCR 및 DB 저장은 이번 검증에 포함되지 않는다.
