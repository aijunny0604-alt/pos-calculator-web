# 네이버 상품·품절 / 재주문 관리

## 진입과 용도

스마트스토어 주문 → **상품·품절 관리**. 기존 주문 필터·발송 처리를 유지한 채 별도 상품 목록을 연다.
네이버 연동 `external_products` 전체 페이지를 읽으며 매장 실물 재고와 별도다.

## 분류

- 상품 품절: `OUTOFSTOCK`.
- 옵션 품절: `SALE`이면서 사용 중인 옵션 재고가 명시적으로 0인 상품.
- 판매중지: `SUSPENSION`. 품절 합계에서 제외한다.
- 판매중 / 기타 상태: 나머지 상품. `CLOSE`는 기타 상태의 판매종료다.
- 상품 상태별 건수는 중복되지 않는다. 비활성 옵션(`usable === false`), 재고 누락·잘못된 값은 옵션 품절로 집계하지 않는다.

## 조회와 상세

상품·옵션명, 번호, 관리코드 검색과 상태 필터를 제공한다. 목록은 40개씩 추가 표시한다.
상품 상세 모달에서 옵션 재고, 추가금액, 비활성 여부, 재고 0만 보기, 공식 상품 링크를 확인한다.
CSV에는 현재 필터의 모든 상품과 옵션을 포함하며 BOM·따옴표 이스케이프·수식 문자열 방어를 적용한다.

화면은 기존 동기화 자료를 30초마다 다시 읽는다. 이는 네이버 API를 30초마다 직접 동기화한다는 의미가 아니다.
상품 동기화 요청은 기존 `request_naver_catalog_sync_now` 경로를 사용한다. 실제 처리는 매장 PC 연동 서비스에 달려 있다.
상품별 동기화 시각을 표시하고 24시간 경과 또는 시각 누락을 경고한다. 조회 실패와 정상 0건은 구분한다.

## 재주문 목록

- 상세에서 개별 옵션, 옵션 정보가 없으면 상품 단위로 담는다.
- **조회 품절 재주문 담기**는 현재 검색·상태 필터의 전체 결과에서 품절 상품·옵션만 담는다. 더 보기 전 항목도 포함한다.
- 상품번호 + 옵션 ID(없으면 옵션명)로 중복을 막는다. 전체 품절이지만 재고 0 옵션 정보가 없는 상품은 상품 단위로 담는다.
- 발주 수량은 빈칸으로 시작한다. 1~999999의 정수로 사용자가 입력한다. 수량 미입력 상태에서는 발주 완료 표시를 막는다.
- 메모, 발주 준비 / 완료 구분, 완료 되돌리기, 제거 및 직전 제거 실행 취소, 검색, CSV를 제공한다.
- 실제 발주 전송이나 네이버/매장 재고 수정은 하지 않는다. 완료 표시는 사용자가 실제 발주 후 수동으로 관리하는 표시다.
- `localStorage`의 `move-store-reorder-v1`에 저장한다. 같은 브라우저의 새로고침·페이지 이동 후 유지하며, 다른 기기·브라우저와 자동 공유하지 않는다. 저장 실패를 알린다. 브라우저 데이터 삭제 시 목록도 사라지므로 CSV로 보관할 수 있다.
- 기존 매입 발주의 재주문 리스트는 매장 제품·판매실적 기준이므로 이 화면과 별도다.

## 검증

- 신규 분류·검색·CSV 테스트 5개와 기존 스토어 조회 테스트 3개 통과.
- 로컬 Chromium 1366×768, 360×800: 목록, 옵션 상세, 재주문 입력을 확인.
- 55개 샘플의 40→55 더 보기, 복합 검색, 옵션 검색, 품절 일괄 담기 중복 방지 확인.
- 수량 12와 메모, 완료 상태의 새로고침 유지 및 완료 되돌리기 확인.
- CSV 다운로드 및 한글·미확인 재고 포함 내용 확인.
- 모달 Escape 닫기와 원래 행 포커스 복귀, Tab / Shift+Tab 순환 확인.
- 모바일 모달 본문 스크롤 가능, 하단 버튼이 뷰포트 안에 배치됨을 확인.
- `stockCheck=failure` 503과 `stockCheck=empty` 빈 결과 안내 확인.
- 개발 전용 fixture는 `design-preview.html?stockCheck=1`. 운영 데이터 변경 없이 검증한다.
- 실기기 Safari/Android, OS 배율·모션 환경 조합, 실제 매장 PC 상품 동기화 완료는 이번 검증 범위 밖이다.

## 배포 상태

사용자 요청으로 테스트·개선 후 운영 배포 진행.

추가 점검에서 누락된 옵션 객체 제외, 저장 실패 시 일괄 담기 화면 전환 방지, 저장된 재주문 자료의 형식·수량 검증, 삭제 실행 취소를 보완했다.
전체 자동 테스트 197개 중 196 통과 / 실패 0 / 환경 의존 1 생략. 최종 빌드 1분 3초 성공. 기존 번들 크기·Rollup 출력 옵션 경고는 유지된다.
로컬 화면에서 제거 → 실행 취소 후 10개 복구를 확인했다.

운영 배포 완료: 기능 소스 `21244cee`, 정적 배포 `8b67e67623e73ae568db21a07cbc19b55049502b`. GitHub Pages는 2026-10-26 19:14:55 KST에 built / 오류 없음으로 완료했다. 운영 주요 자산 13개 HTTP 200 및 로컬 빌드 SHA-256 일치를 확인했다.

운영 연동 자료 738개 중 전체 품절 16개, 일부 옵션 품절 상품 32개(사용 중 재고 0 옵션 47개), 판매중지 448개, 나머지 판매중 240개, 기타 2개를 확인했다. 품절 확인 필요는 중복 없이 48개다. 실제 옵션 상세와 콘솔 오류 없음도 확인했다. 이 수치는 검증 당시 연동 캐시 기준이며, 실제 매장 재고나 실시간 네이버 직접 조회 결과를 의미하지 않는다. 운영 재고·주문·발주 데이터는 변경하지 않았다.
