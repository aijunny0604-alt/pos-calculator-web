# 제품 교체 창 개선 · 2026-10-22

## 변경
- OrderDetail의 제품 교체 UI를 ProductReplacementModal로 분리.
- PC 최대 800 × 720px, 화면이 작으면 가용 뷰포트 안에 고정. 검색 결과 수에 따라 크기나 위치가 바뀌지 않음.
- 현재 제품·검색창·결과 수·취소 고정, 제품 목록만 내부 스크롤.
- PC 2열 / 모바일 1열, 제품명·재고·단가·교체 동작을 분리. 소매 단가는 기존 빨간색 규칙 유지.
- body portal 및 visualViewport 적용으로 부모 모달 transform과 독립. 모바일 키보드가 표시되면 가용 높이 반영.
- Escape는 교체창만 닫음. Tab 포커스 순환 및 닫은 후 기존 포커스 복원. 모바일은 자동 입력 포커스를 하지 않음.
- 기존 제품 선택 콜백, 수량 보존 및 할인 해제 확인 로직 유지.

## 검증
- Codex IAB, 로컬 detailCheck 샘플. 운영 자료 수정 없음.
- 데스크톱: 결과 0/1/30/40건에서 모달 및 검색창 위치·크기 동일.
- 768×1024, 390×844, 360×800: 모달 화면 내 표시, 가로 넘침 없음, 닫기/취소 최소 44px.
- 360×450: 목록 끝까지 키보드 스크롤, 취소 버튼 화면 안 유지. 실제 iOS 키보드 검증을 대신하지 않음.
- 검색 변경 시 목록 상단 복귀. Escape 후 부모 주문 수정창 유지. 취소에서 Tab 입력 시 닫기 버튼으로 순환.
- 샘플 교체: 단가 26,400원 × 기존 수량 2 = 52,800원 확인.
- 브라우저 오류 로그 없음. 자동 테스트 161 통과 / 0 실패 / 1 건너뜀(MOVIS 서버 선택 검증).
