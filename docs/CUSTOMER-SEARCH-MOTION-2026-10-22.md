# 업체 검색·스토어 고객응대·전체 UI 모션 점검

상태: 2026-10-22 로컬 검증 완료. 스토어 발송 반응성 변경과 함께 배포하며 완료 버전은 [배포 기록](DEPLOYMENT-2026-10-22.md)에 기록한다.

## 업체 검색

- 거래처 목록과 업체 교체창/주문 자동완성의 서로 다른 검색 규칙을 `customerMatches`로 통일했다. MainPOS 주문 확인, 명령창의 업체 검색, 명세서 미수업체 검색, 입출금 목록의 업체명 검색에도 적용했다.
- `WP튠 김해`를 `WP김해`, `김해WP`, `WPㄱㅎ`로 검색할 수 있다. 단어 순서·띄어쓰기·전각 문자·분해 한글·초성·전화번호 형식을 처리한다.
- 이름+지역, 이름+전화번호 조합을 지원한다. 전화번호 전체 입력은 숫자 순서를 유지한다. 임의의 한글을 건너뛰는 과도한 유사 매칭과 이름/주소 경계를 이어 붙이는 오탐을 줄였다.
- 검색 결과 없음과 등록된 업체 없음의 안내를 구분했다.
- 후보 검색만 변경했다. 고객 ID 연결, AI 자동 매칭, 주문/명세서 금액 계산과 `orderProductMatches`는 변경하지 않았다.

## 스토어 고객응대 진입점

- 사용자 요청으로 상단 `고객 Q&A · 리뷰 관리` 버튼과 해당 모달을 제거했다. 기존 네이버 관리자 링크는 유지한다.
- Q&A는 별도 PC 연결 프로그램 의존이며 확인 시 `127.0.0.1:43128/session`에 응답이 없었다. 기존 리뷰 UI는 답글 초안 복사만 제공했다.
- 예전 읽기 전용 구현은 소스/개발 미리보기에 보존했다. 과거 Q&A 조회 성공 기록을 API 전체 미지원으로 해석하지 않는다.

## 전체 모션 정책

- 사용자가 프로그램 전체에서 설정과 관계없이 모션을 요청하여 앱 시작 시 `data-move-motion="always"`를 지정한다. 운영·미리보기 진입점 모두 동일하다.
- 전역 reduced-motion 차단 CSS 14개 규칙과 JavaScript 캔버스/타이프라이터 조건 5곳을 공통 정책으로 연결했다. 원래 정의된 애니메이션 속도와 반복 횟수를 유지하며 모든 요소에 임의의 반복 애니메이션을 추가하지 않는다.
- 페이지 전환·기존 모달 모션·카드 호버·버튼 전환과 무비스 모션에 적용된다. 터치 환경의 hover 제한과 인쇄 전용 규칙은 그대로다.
- 무비스: 첫 진입 페이드, 입력창 포커스 강조, 전송 시 은은한 빛 효과, 말풍선 420ms 등장, 답변 520ms 등장, 카드 2px 이동/1.006배 호버.
- 전송 로직을 애니메이션 종료에 연결하지 않았다. 스트리밍에서 완성된 답변으로 바뀔 때 등장 모션을 다시 실행하지 않는다.

## 검증

- 전체 Node 테스트: **169 통과 / 0 실패 / 1 건너뜀** (`MOVIS_TEST_URL` 미지정).
- 최종 Vite 빌드 성공: **58.04초**. 기존 큰 번들/출력 옵션 경고는 별도 개선 대상으로 남아 있다.
- 거래처 목록·업체 교체창·주문 입력에서 역순/초성/전화 조합 및 없는 업체 검색을 확인했다. 샘플 업체 선택 후 이름·전화·주소가 함께 반영됐다.
- 브라우저가 실제 `prefers-reduced-motion: reduce`인 상태에서 페이지 420ms, 모달 360ms, 사용자 말풍선 420ms, 입력창 전환 300ms를 확인했다. 감소 모션 차단 규칙 중 현재 DOM에 적용되는 규칙은 0개였다.
- 마우스 카드 호버의 transform `matrix(1.006, 0, 0, 1.006, 0, -2)`를 확인했다.
- 1280×720, 390×844, 360×800 뷰포트에서 무비스 입력·응답을 점검했다. 모바일 가로 넘침 없음, 전송 버튼 44px와 화면 내 위치 확인. Enter 전송, Shift+Enter 줄바꿈, 스트리밍 완료 시 중복 등장 없음 확인.
- 네이버 관리자 링크 1개 유지, 제거 대상 버튼 0개 확인. 신규 무비스 검증 탭 콘솔 오류 없음. 미리보기 파일 HMR 중 createRoot 재호출 경고는 관찰했으며 운영 동작 오류와 구분한다.
- 실제 iOS 키보드, 실제 Android 기기, 일반 모션 OS 설정으로의 변경은 미실시. 일반/감소 설정 분기는 단위 테스트로 확인했다. 운영 데이터 변경 및 실제 AI 전송은 실행하지 않았다.
