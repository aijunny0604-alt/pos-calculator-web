# 거래처 상세 연락처·배송 주소 표시

연락처와 주소가 작은 글씨로 한 줄에 붙어 보이던 영역을 항목별 라벨과 구역으로 정리했다. PC에서는 연락처와 주소를 나란히 보여주고, 좁은 화면에서는 위아래로 배치한다. 연락처는 20~22px, 주소는 16~18px의 본문색으로 표시하며 긴 주소를 생략하지 않는다.

전화번호·주소 개별 복사와 업체명·연락처·주소 전체 복사를 구분했다. 복사 버튼 높이는 44px 이상이며, 클립보드 쓰기가 성공한 뒤에만 완료를 알린다. 권한 거부 시 실패 안내를 표시한다. 값이 없으면 해당 항목의 미등록 상태를 표시한다. 저장된 업체 정보나 DB 스키마·조회 주기는 변경하지 않는다.

Chromium 샘플 화면에서 1440·768·390·360px 너비의 일반 주소·공백 없는 긴 주소·미등록 상태를 확인했다. 글자 크기, 가로 넘침·주소 잘림 방지, 버튼 높이, 개별·전체 복사 문자열, 권한 거부 안내를 검증했다. 복사 테스트는 격리된 클립보드 대체 객체를 사용해 사용자 클립보드를 변경하지 않았다. 실제 휴대폰과 OS 배율별 테스트는 하지 않았다.

Aside에서 PC DOM 배치를 확인했으며, Aside 캡처 시간 초과로 시각 캡처와 모바일 검증은 저장소에 설치된 Playwright를 사용했다. 기존 공통 버튼·색상·모션 체계를 유지하며 별도의 등장 애니메이션은 추가하지 않았다.
