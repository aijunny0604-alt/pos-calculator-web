# 무비스 첨부 및 연결 안내 개선 (2026-10-13)

- 채팅 영역에 이미지 파일을 드롭하거나 Ctrl+V로 붙여넣을 수 있습니다. 파일 선택도 그대로 지원합니다.
- JPG·PNG·WebP 1장, 최대 5MB입니다. 지원하지 않는 형식·초과 용량·여러 파일은 이유를 표시하며 기존 첨부를 유지합니다.
- 첨부 미리보기·삭제와 이미지+질문 전송을 지원합니다. 텍스트만 붙여넣는 동작은 차단하지 않습니다.
- 이미지를 고르는 것만으로 외부 전송하지 않습니다. 전송 버튼 또는 Enter로 요청합니다. 미리보기 URL은 교체·삭제·화면 종료 시 해제합니다.
- 이미지 읽기 중 중복 전송을 막고 읽기 실패 시 입력을 보존합니다.
- PC 연결 실패와 ChatGPT 인증 필요 상태를 구분합니다. 로그인 버튼이 공식 인증 창을 바로 열며, 팝업 차단 시 직접 여는 링크를 남깁니다.
- 웹 주소에서 PC 연결이 시간 초과되면 PC용 무비스 링크를 제공합니다. 이 링크는 연결 프로그램이 실행 중인 현재 PC에서만 동작합니다.
- Start-MOVIS.ps1의 -BackgroundOnly 옵션으로 Windows 로그인 시 브라우저를 띄우지 않는 일회 실행을 지원합니다. 현재 매장 PC의 시작프로그램 및 바탕화면 바로가기는 별도로 설치되어 있습니다.

검증: tests/movis-attachments.mjs의 합성 이미지·가상 인증 테스트 통과, MOVIS/스마트스토어 기존 30개 테스트 통과. 실제 사용자 이미지나 고객 자료를 AI에 보내지 않았습니다. GPT 인증 완료는 UI 기능 테스트와 별개이며 실제 connected 상태로 확인해야 합니다.

실행: 개발 서버를 127.0.0.1:5174에서 실행한 뒤 node tests/movis-attachments.mjs. 기존 테스트는 MOVIS_TEST_URL을 로컬 /api/movis 주소로 지정하면 브리지 접근 제어도 검사합니다.
